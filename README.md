# FSS + Borg Questionnaire Web App

Flow State Scale（36項目）とBorgスケール（6–20）を用いた研究用Webアンケートアプリ．
質問はランダム順で表示され, 回答結果はCSV形式でダウンロード可能． 

## Features
- FSS 36項目（1–5）
- Borgスケール（6–20）単一選択
- 質問はページ読み込みごとにランダム表示
- 回答結果をCSV形式で保存
- 因子情報（9因子）をCSVに含めて出力

## Usage
1. リポジトリをクローンまたはダウンロード  
2. `index.html` をブラウザで開く  
3. Borgスケール → FSS質問に回答  
4. 「CSVをダウンロード」ボタンをクリック
